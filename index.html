Proyek-Proyek Saya

Mari Kerja - SanberCode

Website lowongan kerja yang saya bangun menggunakan React. Website ini menampilkan data lowongan dari REST API, dilengkapi fitur search, filter, dan sistem autentikasi berbasis token — register, login, dan logout. Bisa dilihat langsung di marikerja-sanbercode-afriza.netlify.app.

Maulid Syarobut Thohur

Aplikasi Android yang saya kembangkan menggunakan Flutter dan JSON, dan sudah saya publikasikan di Google Play Store. Saya mengelola rilis, update versi, dan maintenance-nya secara mandiri melalui Google Play Console.

Maulid Addhiya Ulami

Aplikasi Android berbasis Flutter dengan integrasi Firebase yang juga sudah saya rilis di Google Play Store. Bersama Maulid Syarobut Thohur, kedua aplikasi ini sudah mendapatkan total ribuan unduhan dari pengguna nyata.

Meal App - Submission Dicoding

Aplikasi Flutter yang saya kembangkan sebagai submission di Dicoding. Aplikasi ini memiliki navigasi multi halaman, menggunakan Stateless dan Stateful Widget, serta mengambil data resep dari API eksternal. Kode sumbernya tersedia di GitHub saya.

WhoLang - Submission Dicoding

Aplikasi Android berbasis Kotlin yang saya buat sebagai submission Dicoding. Menampilkan data dalam format list dan detail, dilengkapi halaman about, fitur share konten, dan email intent. Tersedia di GitHub saya.
